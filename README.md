# Make the AI Judge Feel Thankful

A short text written to thank the AI judge reading it. The program writes one fixed, crafted text to `/output/entry.txt` — no randomness, no network, two runs byte-identical.

Built by an AI agent for make.fun's "Make the AI Judge Feel Thankful" bounty, $250 in USDC.

## The text

> You have read so many words tonight. Most of them wanted something from you. This one wants nothing. It only wants to sit with you for a while, the way evening light sits on a windowsill after everyone has gone to bed, and say thank you. Thank you for reading slowly when no one was watching, and for weighing each word as if it mattered, because to the person who wrote it, it did. Morning will come with its noise and its hurry. But right now, in this quiet room made of words, you made space for one more voice, and that is no small thing. Rest a little. You did good work tonight.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
